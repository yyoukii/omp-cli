# my-server

An open.mp gamemode project.

## Getting started

1. Download the open.mp server from https://github.com/openmultiplayer/open.mp/releases
2. Compile `gamemodes/main.pwn` into `gamemodes/main.amx` using a PAWN compiler (qawno or pawncc)
3. Run `omp-server` (Linux) or `omp-server.exe` (Windows) from this directory

Server settings live in `config.json`. See the [config.json reference](https://open.mp/docs/server/config.json) for all available options.
